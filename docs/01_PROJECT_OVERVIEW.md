# Project Overview

Place Review Intelligence transforms restaurant review data, menu and profile information, management observations, and structured evidence into:

- numerical analysis
- topic and sentiment analysis
- management insights
- competitive benchmarking
- action recommendations
- manager presentations

The current primary business is **Al Assiel Restaurant & Shisha, Bonn, Germany**.

The formal competitors are:

- Olivenzweig
- Al Safa
- Beit Fayrouz

## How the Project Flows

```text
Reviews / Restaurant Data
        ↓
Layer 01 — Collection
        ↓
Layer 02 — Preparation
        ↓
Layer 03 — Numerical Analysis
        ↓
Layer 04 — Text Analysis
        ↓
Layer 05 — Reporting
        ↓
Competitive Analysis
        ↓
Management Presentations
        ↓
Implementation & Measurement
```

Layers 02–05 use the selected restaurant's stored database and inputs. Competitive Analysis then compares the four isolated restaurant analyses with common date windows. The presentation builders convert the approved outputs into internal and competitive management reports in English and German.

## Current Status

**Phase 1 is complete.** It produced the internal Al Assiel analysis, formal competitive benchmark, business recommendations, evidence appendices, validated English and German reports, and automated tests.

The current next stage is:

```text
Management presentation → choose actions → implement → monitor → rerun analysis
```
